# 复用 DSH 底层文件能力，但不采用 DSH 工作区模型

LocalFolio 和 DSH 都需要对文件夹做底层操作（列目录、读写、只读预览、搜索）。DSH 的工作区模型是「先添加项目文件夹，再在这个文件夹内操作」，而 LocalFolio 要的是随意浏览任意目录（含外部文件夹）的工作台。因此文件能力复用 DSH 的底层实现，但界面与数据完全由 LocalFolio 自己拥有：不读写 DSH 工作区的数据，不跟随它的生命周期，也不引入「项目文件夹」这一层。本项目里「工作区」只指工作台内的一个视图；指 DSH 的那个概念时必须写「DSH 工作区」。

## Consequences

README 的复用表把 `dsh-api-workspace-files` 描述成「DSH 工作区」能力，容易被读成要接入上面那套工作区模型；该行应改述为「底层文件能力（目录列取 / 只读预览 / 搜索 / 变更流）」。`openFile(filePath)` 这类接口只接收路径，不得假定路径来自 DSH 工作区。
