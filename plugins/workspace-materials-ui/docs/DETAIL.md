# 物料工作区 (`@folio/workspace-materials-ui`)

基于本地 VectorCraft（`vectorcraft-cli` 与 `vectorcraft --control`）的物料整理工作区：

- **左侧项目列表**：每个项目可关联一个或多个固定 A3 横版（420×297mm）`.vectorcraft` 文件，支持新建项目、新建 A3 文件、导入已有文件以及一键在前台 VectorCraft 中打开。
- **第一层（页面管理与导出）**：支持多选、全选页面，直接调用 VectorCraft 原生导出能力输出单张图片（PNG/JPG/WebP/SVG）或多页 PDF。
- **第二层（幻灯片式页面编辑）**：左侧页面缩略图栏支持拖拽调整顺序并自动同步文件中的画板顺序与页码序号；中间为高清页面预览区；右侧为多个快捷下拉输入面板（标题、项目名开关、材质、工艺、尺寸、数量、备注、物料模板），支持后台 CLI 写入与前台打开 VectorCraft 后的实时双向同步。
- **物料数据管理**：完整的数据表格区分**默认数据**与**项目数据**，可增删改、批量删除及跨作用域复制快捷字段选项与物料模板。
