# LocalFolio 工作台套件

## 组成

- **基础能力**（工作台通用）：基础存储能力、基础运行时能力、基础 UI 组件库（`@folio/base-ui-kit`）、基础外壳能力（工作台与悬浮面板）、基础布局框架（`@folio/base-frame-ui`）、基础设置页。
- **测试界面**：测试概览、测试图片画廊、测试侧栏示例、测试 Shadcn Admin、测试 Studio Admin——只为验证界面与集成方式，最终会被删除或并入真实工作区。
- **桥接**：测试框架工作区（`@folio/bridge-frame-test-ui`），把基础布局框架挂进顶部工作区栏，方便随时查看与调整四区布局。

## 使用

1. 安装本套件后，在会话头或对话区顶部出现 `LocalFolio` 入口按钮。
2. 点击进入工作台；顶部工作区栏切换工作区，右侧可开合面板，拖拽边框可调整，双击标题栏最大化。
3. 「测试框架工作区」就是基础布局框架的宿主：左侧应用切换器与面板、中间内容、可折叠可调宽的右侧面板、底部信息栏。
4. 真实工作区接入框架时渲染 `ctx.folioFrame.View` 并调用 `attachHostWorkspace`；只贡献一块功能的功能插件向所在工作区登记。需要自管整个工作区布局或独立悬浮窗口时，仍可用 `ctx.folioShell.registerWorkspace(...)` / `registerFloatingPanel(...)`。
5. 按 `Esc` 或点「返回 DSH」回到原生界面；工作台的打开状态、面板位置与框架内各应用的宽度/折叠状态都会被记住。

## 限制

- 工作台只覆盖在 DSH 原生界面之上，不替换、不改写 DSH 自身的布局与会话视图，也不接入 DSH 工作区模型。
- 悬浮面板的位置记忆保存在浏览器本地存储；换机器或清空站点数据后回到默认位置。
- 设置页的启停开关只控制 LocalFolio 侧的插件记录，DSH 层插件的启停仍以 DSH 插件页为准。
