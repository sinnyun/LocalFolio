# @folio/workspace-canvas-ui · 画板工作区

基于 `@folio/base-frame-ui` 四区布局框架与 `tldraw` 构建的个人无限画板工作区：

- **左侧栏（Left）**：画板列表（新建、搜索、切换、行内重命名、复制、删除、图片数量与断链提醒角标，支持 `Ctrl+B` 折叠为图标轨）。
- **右侧主区域（Main）**：无右侧检查器遮挡的完整 `tldraw` 画布，工具栏、字体、图标与简体中文语言包均由 `@folio/workspace-canvas-host` 本地托管，无外部 CDN 请求。
- **纯链接图片管理**：画板 JSON 仅记录本地文件路径与原始像素尺寸等元信息，严禁复制原图或将 base64 编码写入画板快照。
- **分层 LOD 代理渲染**：根据画布缩放比例（`steppedScreenScale`）与屏幕 DPR 自动请求 `256 / 512 / 1024 / 2048` 四档下采样代理图，服务端通过 Windows WIC `DecodePixelWidth`（及 Shell 缩略图回退）按目标尺寸直接解码并落盘 LRU 缓存，避免超大像素原图拖累渲染与内存。
- **链接管理与断链重选小面板**：通过画布顶部状态胶囊随时打开悬浮小面板，支持单张重新选择本地文件或按文件夹批量重定位已移动的图片。
