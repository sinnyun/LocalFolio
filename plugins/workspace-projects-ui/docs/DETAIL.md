# `@folio/workspace-projects-ui`

基于 `@folio/base-frame-ui` 四区布局框架的项目库工作区。界面分两层：**项目卡片总览** ↔ **项目内部浏览**，左侧栏随层级切换内容。

## 第一层：项目卡片总览（默认）

- **左区（库列表）**：`全部项目` 入口、各归档库的名称/路径/项目数、添加库、单库重新扫描与从索引移除；`全部项目` 与单库之间切换即改变中间卡片网格的范围。
- **中区（项目卡片网格）**：虚拟化卡片网格展示范围内所有项目，含封面缩略图、项目类型、标签、摘要、文件数/体积、变更圆点、缺失标记、AI 提取标记与功能插件徽标；支持项目名/类型/标签搜索、标签与变更筛选、按名称/最近扫描/体积排序、小/中/大三档缩放，以及多选批量管理。
- **右区（范围概览）**：当前范围的项目数、库数、变更数、总体积、库分布、标签分布与最近变更项目；点击标签可筛选，点击库或项目可直接切换范围/进入项目。
- **底区（后台任务条）**：订阅 `/lf/events` SSE `tasks:projects` 主题，实时显示扫描与 AI 批量提取进度、暂停/恢复与取消控制。

## 第二层：进入项目内部

点击任意项目卡片进入项目，此时：

- **左区（项目列表）**：切换为当前库的项目列表，顶部提供「返回项目卡片」、AI 批量提取、多选管理与重新扫描；保留关键词/标签/变更筛选与虚拟滚动列表。
- **中区（项目文件集合视图）**：与文件浏览器共用 `@folio/base-collection-ui` 的 `CollectionBrowser` —— 关键词/分类筛选、`不分组 / 按时间 / 按类型 / 按名称 / 按文件夹` 分组、按名称/修改时间/大小/类型排序 + 升降序、卡片尺寸滑杆、网格/瀑布/等高/列表四视图、可折叠分组头与吸顶分组标题；网格与列表里的缩略图按原始比例完整显示（`contain`），瀑布/等高按测量到的宽高比分配卡片高度。顶部保留项目级动作（返回项目卡片、检测变更、在资源管理器中打开、功能插件工具）与变更提醒条（一键增量更新）。卡片支持双击打开原文件/图片灯箱与右键菜单桥接（打开、定位、设封面、复制路径）。
- **视图偏好**：写入 `localStorage['folio.projects.ui.v1']`，记录 `viewMode / cardSize / groupBy / sortKey / sortDir`；搜索词、分类与折叠状态不持久化。
- **分组数据**：`按文件夹` 直接消费 manifest 的 `groups`（每个目录一组）；其余分组把项目内文件摊平后走共享 `grouping.ts` 分桶，再按当前排序生成同形状的 `ProjectFolderGroup`，所以四种视图与所有分组模式共用一条渲染路径。
- **右区（项目详情与元数据）**：项目体量与类型分布统计、变更明细（`+新增 / ~修改 / -删除`）、DSH AI 一键提取与可编辑摘要/类型/标签、选中文件信息及设为封面操作。
- **底区**：同上，仍显示全局后台任务。

## 多选批量管理

总览与项目列表共用同一套 `ProjectsBatchBar`：已选数量、全选当前筛选结果、清空、AI 批量提取、批量标签弹窗、批量同步，以及功能插件通过 `ctx.folioProjects` 注册的批量动作（如归档）。
