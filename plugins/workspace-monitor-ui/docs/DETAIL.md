# `@folio/workspace-monitor-ui` · 任务监控工作区

跨工作区查看 `@folio/base-tasks-host` 中所有后台任务的中心视图，同时在 DSH 标题栏提供一个可拖动、可缩放的悬浮面板。页面只消费 `ctx.folioTasks` 的客户端配套 Hook 与 RPC 动作，不直接持有任务状态。

## 能做什么

- **按工作区 / 项目 / 状态筛选**：工作区卡片显示活跃、有失败与待继续数量；项目与关键词筛选跨所有 scope。
- **持久化视图状态**：工作区、项目、状态筛选、搜索词与展开的任务写入 `localStorage['folio.monitor.v1']`；刷新页面或切换工作台后原样恢复。
- **完整进度**：分段进度条区分成功 / 失败 / 跳过 / 取消 / 处理中；显示已处理数、耗时、按当前速率估算的剩余时间以及最近错误。
- **暂停 / 停止 / 继续 / 取消**：
  - 暂停：协作式暂停，正在处理的子项完成后不再启动新子项；
  - 停止：中止当前子项并保留未完成项，任务进入 `stopped`；有重试处理器时可「继续」；
  - 继续：暂停任务在同一任务内继续；停止或应用重启后的中断任务通过生产者的重试处理器新建任务继续；
  - 取消：终止任务并把未完成子项标记为取消。
- **子项明细与重试**：任务展开后按「全部 / 失败 / 未完成 / 成功」浏览子项；支持单勾、全选当前可重试项、重试选中、重试全部失败与逐行重试。已重试项显示「已重试」，来源任务显示衍生重试任务数量。
- **历史与清理**：已完成、失败、取消、停止与中断的任务都来自持久化账本，重启后仍在；「清理历史」只删除已结束任务。

## 数据来源

| 来源 | 用途 |
|---|---|
| `useFolioTasks({ scopes: 'all' })` | 任务列表、SSE 增量与 pause/resume/stop/cancel/retry 动作 |
| `useTaskItems` / `fetchTaskItems` | 单个任务的子项分页，展开时按需拉取，活跃任务轮询刷新 |
| `localStorage['folio.monitor.v1']` | 仅 UI 偏好；任务与子项由 Host 账本持久化 |

## 入口

- 工作台工作区：`folio.frame` 应用 `monitor.tasks`（`MainView` 为 `ctx.folioFrame.WorkspaceHost`）。
- 悬浮面板：`monitor.tasks.floating`，默认 640×560，最小 370×280。
- 标题栏按钮：`monitor.tasks.toggle`，调用 `ctx.folioShell.toggleFloatingPanel`。

## 限制

- 子项明细单次最多返回 5000 项（Host 端上限），超出时任务会标记 `itemsTruncated`，页面提示仅保留前 5000 项。
- 停止 / 继续依赖生产者协作：长任务需在子项边界调用 `helpers.items.checkpoint()`；没有登记 `retry` 描述符与重试处理器的任务只能停止或取消，不能继续。
- 子项列表只展示已登记子项的任务；旧任务仍以 `progress.detail` 的聚合计数与传统失败信息呈现。
