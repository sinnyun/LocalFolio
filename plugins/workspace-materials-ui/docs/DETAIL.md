# @folio/workspace-materials-ui · 物料

物料整理与排版工作区的**界面层**，形态 A：它把 `@folio/base-frame-ui` 的四区框架当作自己的 `MainView`，声明左栏、主区与底栏，主区在「页面管理 / 幻灯片式编辑 / 物料数据表格」三个视图之间切换。`@folio/workspace-materials-ui` 本身只画界面并驱动 RPC；解析 `.vectorcraft`、写信息头、导出、监听文件与渲染预览都在 `@folio/workspace-materials-host`（见 `plugins/workspace-materials-host/docs/DETAIL.md`）。

```text
┌ Left ──────────────────┬ Main ──────────────────────────────────────────────┐
│ 项目列表（n 文件）     │ 第一层 pages：文件筛选 · 多选导出 · 页面网格       │
│ ＋ 新建项目 / 搜索     │ 第二层 editor：页面栏 ─ 预览台 ─ 物料信息栏        │
│ ▸ 文件子列表（n 页）   │ 第三层 data：默认 / 项目 两套物料数据表格          │
│ ─ 物料数据管理         │ 导出弹窗 · 项目/新建文件/设置弹窗                  │
│ ─ VectorCraft 设置     │ 空态、忙标记与三层切换都在视图内部                 │
├────────────────────────┴────────────────────────────────────────────────────┤
│ Status：项目名 · 当前层 · n 文件 / n 页 · 已选 n 页 · 连接状态              │
└─────────────────────────────────────────────────────────────────────────────┘
```

没有 `Right` 区：第二层右侧的「物料信息栏」是主区内部的一栏，不是框架的右栏。

## 它做什么

把「一个项目 → 多个 A3 横版 `.vectorcraft` 文件 → 多张画板（页面）」这条结构画出来，并提供三件事：**批量导出**（选页 → 导出单图或多页 PDF）、**逐页改物料信息头**（快捷下拉 → 写回画板 → 文件里立刻可见）、**维护两套物料数据**（全局默认 + 当前项目）。它不解析文件、不生成命令、不直接改 `.vectorcraft` 字节。

## 四区声明

`createMaterialsApp()` 返回的 `FrameAppDefinition`：

| 区域 | 组件（`src/components/`） | 职责 |
|---|---|---|
| 左 `Left` | `MaterialsSidebar` | 项目列表、当前项目的文件子列表、物料数据入口、VectorCraft 设置入口与连接状态 |
| 中 `Main` | `MaterialsMain` | 按 `viewLayer` 渲染三个视图，并挂导出弹窗与项目/新建文件/设置弹窗 |
| 右 `Right` | — | 未声明 |
| 底 `Status` | `MaterialsStatus` | 项目名、当前层名称、文件/页数、已选页数、实时联动或 CLI 就绪状态 |
| `Provider` | `MaterialsProvider`（`src/context.tsx`） | 项目、文件状态、目录数据、选择、视图层、预览版本号 |

```ts
id: 'materials.workbench', workspaceId: 'materials', order: 1,
title: '物料', subtitle: 'VectorCraft A3 物料整理与导出', leftCollapse: 'icon',
defaultLayout: { leftWidth: 264, leftCollapsed: false },
```

工作区贡献是 `id: 'materials'`、`order: 4`、`fileExtensions: ['.vectorcraft']`、`MainView: ctx.folioFrame.WorkspaceHost`——外壳会把打开的 `.vectorcraft` 交给这个工作区（见「限制与边界」里关于目标传递的说明）。

## 页面结构与三层视图

`viewLayer` 只有三个值，底栏会写出当前层全名：

| 层 | 组件 | 结构 |
|---|---|---|
| `pages` 第一层 | `PagesOverviewView` | 两行工具条 + 页面缩略图网格（1/2/3/4 列自适应） |
| `editor` 第二层 | `PageEditorView` | 顶部工具条 + 三栏：`SlidePageRail`（`w-56`）/ `PagePreviewStage` / `MaterialInfoPanel`（`w-80`） |
| `data` 第三层 | `MaterialDataManagerView` | 顶部作用域与操作条 + 二级切换 + 数据表格 |

第一层工具条：项目名与「n 文件 · n 页」、`新建 A3 页面`、`按模板加页`（项目模板在前、默认模板在后）、`在 VectorCraft 打开`、`同步刷新`、`物料数据管理`；第二行是文件筛选胶囊（`全部文件` + 每个文件及其页数）、`全选/取消全选`、已选计数、`导出单张图片`、`导出多页 PDF`。

页面卡片按 `420 / 297` 显示 `72 PPI` 预览，左上角多选框、右上角页码徽标（非 A3 时多一个 `非A3·点击统一`）、下方是「页码 - 标题」与规格摘要行（`材质 / 工艺 / 尺寸 / 数量 / 备注` 以 ` | ` 连接，空则显示占位文案），底部是 `编辑页面`、复制、删除。**双击卡片**直接进第二层。

空态分三级：没有项目 → 「还没有物料项目」+ 新建；有项目没文件 → 「当前项目暂无 VectorCraft 文件」+ 新建 / 导入；有文件没画板 → 「未解析到画板页面，请检查所选 .vectorcraft 文件是否有效」。

## 主要交互

**左侧项目列表**：单击切换项目（切换会清空页面选择、退出第二层、回到第一层）；双击项目名行内重命名（`Enter` 提交 / `Esc` 取消 / 失焦提交）；「…」菜单是 `新建 A3 横版文件`、`导入 .vectorcraft 文件`、`项目物料数据`（切到第三层并停在项目作用域）、`重命名项目`、`删除项目`；搜索同时匹配项目名与其中文件名。活动项目展开文件子列表：状态点（绿=前台正在编辑、琥珀=文件不存在、蓝=正常）、文件名、`n页` 徽标、缺失警告；点文件把它设为第一层的文件筛选（再点一次取消回 `全部文件`，在第三层时顺手切回第一层）。文件行的「…」是 `在 VectorCraft 中打开`、`在资源管理器中显示`、`从项目移除`。底栏两个入口：`物料数据管理`（第三层开关）与 `VectorCraft 设置`（带 `实时 / CLI / 未就绪` 状态点）。

**第二层页面编辑**：

| 交互 | 说明 |
|---|---|
| 拖拽排序 | 页面栏卡片可拖（全局 `mutating` 时禁用），拖到目标行后调 `materials.pages.reorder`，落定后页码与信息头里的序号由 Host 重排；悬停出现 `上移 / 下移` 按钮做同样的事 |
| `↑` / `↓` | 在非输入框（不是 `input/textarea/contenteditable`）时切上一页 / 下一页；输入框里不抢键 |
| 缩略图点击 | 切换当前页；预览台两侧 `‹ ›` 与 `n / total` 同样切页 |
| 预览缩放 | 缩小 / 放大按钮每档 15%，范围 `50%–200%`；`适应画布` 回到适应宽度并重置 100% |
| 复制 / 删除页 | 卡片悬停按钮；只剩一页时删除禁用，加页按钮在页面栏顶部 |
| 顶部工具条 | `返回页面管理`、跨文件切换（多于一个文件时是下拉框，切文件回到第 1 页）、前台联动状态徽标、`双向同步`、`在 VectorCraft 打开此页`、`导出图片`、`物料数据` |

**物料信息栏**（第二层右栏）：头部是 `存模板`（当前页 → 项目模板）与 `写入画板`（强制提交，`mutating` 时转圈禁用），下面依次是模板快选、`画板顶部左侧`（自动序号 + 物料标题）、`显示项目名称` 开关与自定义名称、`画板顶部右侧` 的五个快捷下拉；底部是顶部信息条预览（左「序号 - 标题 - 项目名」、右规格串）与 `输入中... / 已同步` 状态。

**快捷下拉输入面板**（`QuickPickComboBox`）：聚焦展开菜单，分「项目数据（当前项目）」与「默认数据」两段；输入即按值 / 标签 / 描述过滤；点选项直接选中并提交，`Enter` 提交当前输入，`Esc` 关闭，右侧 `×` 清空、`⌄` 手动展开。输入值不在任何预设里时标题行出现 `存入项目`（写进项目作用域选项）；`工艺` 与 `备注` 支持追加（以 ` / ` 接在已有内容后面）。提交策略：选预设、切开关、套模板、点 `写入画板` 立即写；手打文字走 450ms 防抖写。

**第三层数据表格**：作用域 Tabs 是 `默认数据（全局）` 与 `项目数据（当前项目）`（没有活动项目时后者禁用），默认作用域额外有 `恢复默认数据`；二级 Tabs 是 `快捷字段选项表 (n)` 与 `物料模板表 (n)`；选项表可按 `全部 / 材质 / 工艺 / 尺寸 / 数量 / 备注 / 常用标题` 过滤；两张表都支持表头全选（作用于当前筛选结果）、行多选、`批量删除 (n)`、逐行编辑/删除。选项行有 `复制到项目` 或 `设为默认`；模板行额外有 `加页`（用该模板在项目第一个文件里新建一页）。搜索在选项表匹配值/说明/分类名，在模板表匹配所有字段。

## 导出

`ExportDialog` 由第一层两个按钮（预置 `png` / `pdf-merged`）或第二层 `导出图片` 打开：

| 项 | 行为 |
|---|---|
| 格式 | 多页 PDF（合并）、单页 PDF（每页独立）、PNG、JPG、WebP、SVG 六种 |
| PPI | 只有栅格格式显示，三档 `72 / 150 / 300` |
| PDF 文件名 | 只在「多页 PDF（合并）」时出现，默认 `<项目名>_物料` |
| 导出目录 | 必填；默认取设置里的 `defaultExportDir`（首次为空则手填），`浏览` 走原生文件夹选择 |
| 完成后定位 | 开关，默认开 |
| 约束 | 无选中、无目录或正在 `mutating` 时「开始导出」禁用；成功后关闭弹窗并提示生成文件数 |

第二层顶部的 `导出图片` 是快捷路径：页面上没有其它选中项时直接把**当前页**按 `150 PPI` 导出到上次目录（没有就弹文件夹选择，取消则退回导出弹窗）；已有选中项时打开弹窗按选中项导出。

## 物料数据：默认与项目

- 两套数据各自有「快捷字段选项」与「物料模板」。六个字段分类固定：`title / material / craft / size / quantity / note`。
- 用途差异：**默认数据**是全局底稿（Host 内置 50 条选项 + 8 个模板，可一键恢复）；**项目数据**是当前项目私有，页面上 `存入项目`、`存模板` 都写到这里。
- 跨作用域复制是显式动作（`复制到项目` / `设为默认`），不是继承；下拉里两段并列展示，项目段在前。
- 删除项目在菜单里点一下即执行，没有二次确认；项目级物料数据由 Host 一并清掉。

## 与 VectorCraft 的双向同步（界面上的体现）

| 位置 | 表现 |
|---|---|
| 第二层状态徽标 | `前台 VectorCraft 实时联动` / `前台 VectorCraft 编辑中（未保存）` / `后台 CLI 模式` |
| 物料信息栏徽标 | `前台实时写入` / `CLI 后台写入` |
| 底栏 | `VectorCraft 前台实时联动 :<port>`、`<CLI 版本> 就绪`、`未检测到 VectorCraft CLI` 三态 |
| 第二层 `双向同步` / 第一层 `同步刷新` | 主动探测前台并重解析（`materials.vc.syncNow`） |
| 左侧状态点 | 文件正在前台打开时变绿 |
| 设置弹窗 | CLI / GUI 检测徽标、控制通道连接状态，以及「监听文件保存变更」「轮询前台控制通道」两个开关 |

被动方向由 Host 驱动：文件监听与前台轮询（每 2.5s）触发 `materials` 作用域的失效事件，界面监听 `window` 上的 `folio:invalidate` 后整体 `refreshAll()`；每次刷新都会推进 `previewRev`，预览 URL 因此换 `v=` 重新取图。字段级冲突按 Host 的「文件优先」规则解析（见 Host 文档），界面只负责把重解析后的 `fields` 渲染出来；本地正在编辑（`dirty`）时不会被外部值覆盖草稿。

## 数据与状态

调用的 Host 动作（只说明界面为什么调）：

| 动作 | 界面侧用途 |
|---|---|
| `materials.status` / `materials.settings.update` | 底栏与左栏的连接状态、设置弹窗 |
| `materials.projects.list` / `create` / `update` / `delete` | 项目列表、新建、重命名/设为当前、删除 |
| `materials.files.add` / `create` / `remove` | 导入文件、新建 A3 文件、从项目移除 |
| `materials.project.inspect` | 每次刷新拿整项目的文件与页面状态 |
| `materials.pages.updateHeader` / `add` / `duplicate` / `delete` / `reorder` / `normalizeA3` / `syncAllHeaders` | 信息栏写入、加页、复制、删除、拖拽排序、非 A3 统一、整文件重绘信息头 |
| `materials.vc.open` / `syncNow` | 前台打开（可定位到当前页）、主动同步 |
| `materials.export` | 选页导出 |
| `materials.catalog.*` | 两套选项与模板的增删改、跨作用域复制、恢复默认 |
| `materials.dialog.pickFiles` / `pickSaveFile` / `pickFolder`、`materials.files.reveal` | 原生选择框与资源管理器定位 |

- 预览是唯一的路由消费：`/lf/materials/preview?path=&artboard=&ppi=&v=`，拇指用 `72 PPI`，第二层大图用 `144 PPI`。
- **没有 `localStorage`**：三层视图、作用域、筛选、选中页、编辑草稿、弹窗开关全是内存态；刷新回到「第一层 + 上次活动项目（Host 记的）+ 空选择」。
- 选择以 `fileId::artboardIndex` 为键；切项目时清空，切文件筛选时不清空。
- `mutating` 是一个全局忙标记：写类动作期间按钮转圈/禁用，避免用户在一次 CLI 批处理没结束时再排一次。

## 与 Host 的分工

- 界面负责：项目与文件的呈现、页面选择与导出编排、三个视图的布局、信息栏表单与防抖提交、快捷选项的展示、数据表格的增删改界面、两个原生选择框的调用。
- Host 负责：CLI / 前台控制通道、`.vectorcraft` 解析与写回、信息头命令生成、页码与画板重排、导出落盘与命名、预览渲染与缓存、文件监听与轮询、两套物料数据的持久化。
- 界面**不缓存**任何物料数据：`materials.catalog.*` 的每个写操作都返回完整 `CatalogResponse`，界面整块替换；页面写操作返回整份 `MaterialFileState`，界面按 `fileId` 替换该文件。

## 限制与边界

- 选中与可见范围不一致：导出时只会导出「当前文件筛选下可见 ∩ 已选」的页面，但计数器仍然统计所有已选键。切了文件筛选后直接点导出，可能提示「请先选择至少要导出的页面」或导出数小于显示数。
- 文件路由目标拿不到：`MaterialsProvider` 实现了 `pendingTarget` / `consumePendingTarget`（收到 `.vectorcraft` 路径时若无项目会先建「默认物料项目」再 `materials.files.add`），但经四区框架挂载时 `FrameAppDefinition.Provider` 只收到 `appId / frame / children`，这两个 props 不会被传入，所以今天从外壳打开 `.vectorcraft` 只会切到本工作区，不会自动加入项目。
- 非 A3 页面不会被拒绝：导入的 `.vectorcraft` 可以是任意尺寸，界面用 `非A3·点击统一` 与 `转为 A3 横版` 把选择权交给用户，统一动作走 Host 的 `normalizeA3`（会重排全部页码）。
- 新建 A3 文件的页数被夹在 `1–50`；删页到只剩一页时按钮直接禁用（Host 侧也保底一页）。
- 三个原生选择框仅 Windows 可用；不支持时导入文件只弹提示（`当前环境不支持原生文件对话框，请使用路径输入`），新建文件仍可手填路径。
- 第二层的 `↑ / ↓` 挂在 `window` 上：焦点在输入框、文本域或可编辑区时不触发，但焦点在按钮上也仍会切页。
- 信息栏是 450ms 防抖写：连续输入期间只有最后一次落盘，期间顶部信息条预览已经按草稿变化。切页会清掉待写草稿（换页即重载 `fields`）。
- 第三层的作用域初值只在组件挂载时取一次 `dataScopeDefault`；停留在第三层时从左侧切项目，作用域不跟着改。
- 不做排版本身：画布与图层的编辑仍在 VectorCraft 里，界面只碰信息头、画板顺序与导出。
