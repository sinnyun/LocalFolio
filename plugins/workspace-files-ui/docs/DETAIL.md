# @folio/workspace-files-ui · 文件浏览器工作区

LocalFolio 的首个正式产品工作区，采用形态 A（`@folio/base-frame-ui` 四区布局框架）：

- **左侧栏（Left）**：快捷文件夹（支持固定/取消固定）、本地驱动器及容量进度条、按需懒加载的文件树（支持定位当前目录）。
- **中间浏览区（Main）**：支持单栏与双栏并排浏览；每栏独立提供前进 / 后退 / 上一级 / 刷新、点击可编辑的面包屑路径栏（`Ctrl+L`）、实时筛选与类型过滤、网格 / 列表视图切换、网格大小调节（`96px–240px`）、五种分组方式（不分组 / 时间 / 类型 / 名称 / 父子文件夹）与排序。
- **缩略图与媒体预览**：直接调用 Windows 系统自带缩略图与系统缓存（`IShellItemImageFactory`），不在工作区重复实现缩略图生成与磁盘缓存。
- **右侧检查器（Right，可折叠 `Ctrl+Alt+R`）**：原图预览与灯箱大图、音视频播放、代码/文本片段预览、详细元数据、一键复制完整路径及在系统资源管理器中打开。
- **扩展规划**：后续文件编辑与扩展功能将作为独立的 `feature-*` 功能插件挂载到本工作区。
