# LocalFolio 工作台套件

## 功能

- 九件套一键安装：存储底座、运行时网关、共享 UI 基础组件库（`@folio/core-ui-kit`）、工作台覆盖层、悬浮面板宿主、我的插件设置页，以及三个独立界面样板（概览、图片画廊、侧栏示例）。
- 每个插件独占 `%LOCALAPPDATA%\LocalFolio\plugins\<插件>\{data,cache}`，互不可见。
- 浏览器侧插件通过 `/lf/*` RPC 与 SSE 与 Host 通信，按 DSH 连接身份与同源策略放行。

## 使用

1. 安装本组合包后，在会话头或对话区顶部出现 `LocalFolio` 入口按钮。
2. 点击进入全屏工作台；左侧切换工作区，右侧可开合面板，拖拽边框可调整，双击标题栏最大化。
3. 任何 `@folio/app-*-ui` 插件调用 `ctx.folioShell.registerWorkspace(...)` 或 `registerFloatingPanel(...)` 即可出现在工作台里。
4. 按 `Esc` 或点「返回 DSH」回到原生界面；工作台的打开状态与面板位置会被记住。

## 限制

- 工作台只覆盖在 DSH 原生界面之上，不替换、不改写 DSH 自身的布局与会话视图。
- 悬浮面板的位置记忆保存在浏览器本地存储；换机器或清空站点数据后回到默认位置。
- 设置页的启停开关只控制 LocalFolio 侧的插件记录，DSH 层插件的启停仍以 DSH 插件页为准。
