# `@folio/workspace-projects-ui`

基于 `@folio/base-frame-ui` 四区布局框架的项目库工作区前端界面。

## 四区职责

- **左区（项目列表）**：库切换下拉框、添加/重扫/移除库、关键词与标签筛选、变更标记圆点、多选批量管理（全选、AI 批量提取、批量标签、批量同步）、右键项目菜单，以及基于虚拟滚动的千级项目列表。
- **中区（分组卡片视图）**：顶部变更提醒条与一键增量更新、卡片缩放（小/中/大）、排序与分类筛选、吸顶文件夹分组头与可折叠虚拟卡片网格、双击打开原文件/图片灯箱与右键菜单桥接（打开、定位、设封面、复制路径）。
- **右区（项目详情与元数据）**：项目体量与类型分布统计、变更明细（`+新增 / ~修改 / -删除`）、DSH AI 一键提取与可编辑摘要/类型/标签、选中文件信息及设为封面操作。
- **底区（后台任务条）**：订阅 `/lf/events` SSE `tasks:projects` 主题，实时显示扫描与 AI 批量提取进度、暂停/恢复与取消控制。
